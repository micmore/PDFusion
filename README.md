# PDFusion

**PDFusion** is a one-stop solution for merging files of various formats into a single, cohesive PDF. Built with an intuitive Tkinter interface, this versatile tool supports images, text files, Word documents, and existing PDFs, making document management a breeze.

## Features

- **Multi-Format Compatibility**: Merge images (JPG, PNG, BMP, TIFF), text files (TXT), Word documents (DOCX), and PDFs.
- **Batch Management**: Add up to 30 files for simultaneous merging.
- **Intuitive Interface**: A clean and straightforward graphical user interface makes merging files effortless.
- **Custom Save Options**: Specify the name and location for the resulting PDF file.
- **Smart Handling**: Error alerts for unsupported formats and operational issues ensure a smooth experience.

## Installation

Before running PDFusion, install the following dependencies:

- Python 3.x
- Required libraries:
  - `tkinter`
  - `Pillow`
  - `PyPDF2`
  - `fpdf`
  - `python-docx`

Install dependencies using `pip`:

```bash
pip install pillow PyPDF2 fpdf python-docx

# Usage

- **Launch PDFusion**: Run the application to open the main interface.
- **Add Files**: Click "Add File" to select files for merging.
- **Manage Files**: View and remove selected files from the list as needed.
- **Merge and Save**: Click "Merge to PDF," then choose a name and location for the output.
- **View Success Message**: A confirmation popup will notify you when your PDF is ready.
